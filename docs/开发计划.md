# new BV 开发计划

> 配套文档：[PRD](PRD.md) | [AGENTS.md](../AGENTS.md)
> 本文档将 PRD 的需求分解为可执行的开发任务，按阶段推进，每阶段含明确验收标准。

---

## 总体节奏

new BV 采用 **4 个阶段** 迭代开发，与 PRD 第 9 章的 Milestone 对齐：

| 阶段 | 名称 | 目标 | 对应 PRD Milestone |
|---|---|---|---|
| Phase 0 | 基础架构搭建 | 项目骨架可编译可运行 | M1 |
| Phase 1 | 核心功能（VOD） | 完整点播观看流程，对标原版 BV | M2 |
| Phase 2 | 新增核心功能 | 直播 + 触屏 + 评论 + 主题 + 日志体系 | M3 |
| Phase 3 | 增强与打磨 | P2 功能 + 稳定性 + 性能优化 | M4 |

**测试策略**：每个任务必须同步产出测试，不允许"先功能后补测"。测试不通过的 PR 不合并。
