# 直播功能开发计划（P2-1）

> 本文档是 newBV 直播功能的详细开发计划，基于 Playwright 抓取 B 站直播 Web 端 + API 文档 + 原版 BV 源码分析编写。

---

## 1. 概念说明

| 概念 | 说明 |
|---|---|
| **直播间（Room）** | B 站直播的基本单位，每个主播有一个直播间，包含 room_id、标题、封面、分区、在线人数等 |
| **短号 / 长号** | 短号（如 `721`）是易记的房间号，需通过 `room_init` API 转换为真实长号（如 `3044248`）才能获取流地址 |
| **分区（Area）** | 直播分两级：父分区（网游/手游/单机/虚拟主播/娱乐/电台/赛事/聊天室/生活）和子分区（英雄联盟/无畏契约/...） |
| **弹幕 WebSocket** | 直播弹幕通过 WebSocket 实时推送，连接 `wss://{host}:{wssPort}/sub`，需先获取 token |
| **流协议** | B 站直播支持 FLV（http_stream）、HLS-TS（http_hls/ts）、HLS-FMP4（http_hls/fmp4）三种协议 |
| **画质（qn）** | 流畅(80) / 高清(150) / 超清(250) / 蓝光(400) / 原画(10000) / 2K(15000) / 4K(20000) / 杜比(30000) |

### 3.3 关键 API 参数与响应

#### 3.3.1 分区直播列表（#7）

**端点**: `GET /xlive/web-interface/v1/second/getList`

**参数**:

| 参数 | 类型 | 必要 | 说明 |
|---|---|---|---|
| `platform` | String | 是 | 固定 `web` |
| `parent_area_id` | Int | 是 | 父分区 ID |
| `area_id` | Int | 是 | 子分区 ID（0=全部） |
| `sort_type` | String | 否 | `sort_type_2221`=热门, `live_time`=最新, `sort_type_2223`=萌新 |
| `page` | Int | 否 | 页码，从 1 开始 |
| `web_location` | String | 否 | 埋点，可省略 |

**响应**:
```json
{
  "code": 0, "data": {
    "banner": [...],
    "new_tags": [
      {"id": 2221, "name": "热门", "sort_type": "sort_type_2221"},
      {"id": 2222, "name": "最新", "sort_type": "live_time"},
      {"id": 2223, "name": "萌新", "sort_type": "sort_type_2223"}
    ],
    "list": [LiveRoomItem, ...],  // 每页 ~20 条
    "count": 0,
    "has_more": 1                  // 1=有更多
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `roomid` | Int | 直播间 ID（可能是短号） |
| `uid` | Long | 主播 UID |
| `title` | String | 直播间标题 |
| `uname` | String | 主播用户名 |
| `online` | Int | 在线人数（人气值） |
| `cover` | String | 封面图 URL |
| `face` | String | 主播头像 URL |
| `keyframe` | String | 关键帧截图 URL |
| `area_v2_id` | Int | 子分区 ID |
| `area_v2_name` | String | 子分区名 |
| `area_v2_parent_id` | Int | 父分区 ID |
| `area_v2_parent_name` | String | 父分区名 |
| `watched_show` | Object | 观看数 `{num, text_small, text_large}` |
| `pendant_info` | Object | 挂件信息（TopStar/SSS主播 等标签） |

#### 3.3.3 直播流地址 v2（#10）

**端点**: `GET /xlive/web-room/v2/index/getRoomPlayInfo`

**参数**:

| 参数 | 类型 | 说明 |
|---|---|---|
| `room_id` | Int | 真实房间号（长号） |
| `protocol` | String | `0,1`（0=FLV, 1=HLS） |
| `format` | String | `0,1,2`（0=FLV, 1=TS, 2=FMP4） |
| `codec` | String | `0,1,2`（0=AVC, 1=HEVC, 2=AV1） |
| `qn` | Int | 画质（0=自动） |
| `platform` | String | 固定 `web` |
| `ptype` | Int | 固定 `8` |

**响应结构**:
```
data: {
  room_id, short_id, uid, live_status,  // 0=未开播 1=直播中 2=轮播
  playurl_info: {
    playurl: {
      cid,
      g_qn_desc: [{qn, desc}],           // 可选画质列表
      stream: [{                        // 协议数组
        protocol_name: "http_stream" | "http_hls",
        format: [{
          format_name: "flv" | "ts" | "fmp4",
          codec: [{
            codec_name: "avc" | "hevc",
            current_qn: 250,
            accept_qn: [10000, 250],
            base_url: "/live-bvc/...",
            url_info: [{
              host: "https://xxx.bilivideo.com",
              extra: "expires=...&qn=250..."
            }],
            media_info: {height, width, realtime_avg_bw}
          }]
        }]
      }]
    },
    expected_quality: {qn, ...}
  }
}
```

**完整流 URL** = `url_info[0].host` + `codec.base_url` + `url_info[0].extra`

**HLS 流**：`base_url` 以 `.m3u8` 结尾（fmp4 格式）或 `.m3u8` 结尾（ts 格式）
**FLV 流**：`base_url` 以 `.flv` 结尾

## 5. 流地址选择策略

```
1. 从 stream 数组中找 protocol_name="http_hls"
2. 在 HLS format 中优先找 format_name="fmp4"，fallback 到 "ts"
3. 在 codec 中优先找 codec_name="avc"，fallback 到 "hevc"
4. 取 url_info[0] 拼接：host + base_url + extra
5. 如果 HLS 不可用，fallback 到 http_stream / flv
6. 如果 v2 接口失败，fallback 到 getLiveStreamUrl 简单接口
```

**默认优先 HLS**：ExoPlayer 原生支持 HLS（`.m3u8`），FLV 需要额外 extension。
