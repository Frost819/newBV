# 触屏适配计划

> 基于 P0-2 `InteractionTracker` 基础设施，对所有 D-pad-only 交互组件进行触屏适配。

## 总览

17 个组件排查（排除 3 个 by design），14 个需适配（Tab 刷新已实现），分 6 个 Phase。

### 不适配（by design）

| 组件 | 原因 |
|---|---|
| `UnlockUserScreen` 方向锁 | TV 安全设计，D-pad 方向键输入密码 |
| `UserLockSettingsScreen` 方向锁设置 | 同上 |
| `PlayerCustomShortcutsDialog` 按键捕获 | 设计上需要物理按键 |

### 已实现（无需改动）

| 组件 | 说明 |
|---|---|
| TopNav Tab 点击刷新 | 4 个内容页（Home/Pgc/Ugc/Personal）已接入 `onClick = { viewModel.refresh() }` |

---

## Phase 1: `onClick = {}` 空实现修复（6 个组件）

**根因**：选择逻辑在 `onFocus` 回调里，`onClick` 是空的。触屏点击触发 `onClick`（无效），不触发 `onFocus`。

| # | 文件 | 行号 | 修改 |
|---|---|---|---|
| 1 | `MenuNav.kt` | 59 | `onClick = { onSelectedChanged(item) }` |
| 2 | `PictureMenu.kt` | 173 | `onClick = { selectedPictureMenuItem = item }` |
| 3 | `DanmakuMenu.kt` | 209 | `onClick = { selectedDanmakuMenuItem = item }` |
| 4 | `ClosedCaptionMenu.kt` | 169 | `onClick = { selectedCcMenuItem = item }` |
| 5 | `SettingsScreen.kt` | 232 | `onClick = { onFocus() }` |
| 6 | `MediaCodecScreen.kt` | 152 | `onClick = { onCodecInfoDataChanged(codecInfoData) }` |

### 播放器手势映射（PRD 4.3.3.2）

| 手势 | 动作 |
|---|---|
| 单击 | 显示/隐藏控制器 |
| 双击 | 播放/暂停 |
| 左右滑动 | 快进/快退 |
| 上下滑动（左半屏） | 亮度调节 |
| 上下滑动（右半屏） | 音量调节 |
| 长按 | 倍速播放（2x），松手恢复 |
| 捏合 | 缩放（宽高比循环） |
