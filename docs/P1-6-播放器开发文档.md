## 1. 架构概览

### 1.1 设计决策

| 决策 | 选择 | 原因 |
|---|---|---|
| ViewModel 拆分 | 严格 5-way 拆分 | AGENTS.md §6.5 要求 ≤300 行/VM |
| 数据共享 | Hilt `@Singleton` VideoInfoRepository | 详情页与播放器共享视频列表/详情状态 |
| 自定义快捷键 | 数据模型 + 执行逻辑（配置 UI 延后到 P1-9） | P1-9 设置页负责配置界面 |
| 实现策略 | 增量构建，每阶段 build check | 尽早发现问题 |

### 1.2 原版 → newBV 转换对照

| 原版 BV | newBV |
|---|---|
| `koinViewModel<VideoPlayerV3ViewModel>()` | `hiltViewModel<PlayerViewModel>()` + 4 个同级 VM |
| `VideoPlayerV3Activity` + Intent extras | Compose Navigation `VideoPlayerRoute(aid, cid, epid?, title, cover)` |
| `VideoInfoRepository` (Koin singleton) | `VideoInfoRepository` (Hilt `@Singleton`) |
| `Prefs.playerCustomShortcuts` (Koin) | `Prefs.playerCustomShortcuts` (DataStore，已实现) |
| `ProxyArea` / `replaceUrlDomainWithAliCdn` | **删除** |
| `R.string.video_player_user_agent_*` | 硬编码常量 UA 字符串 |
| `dev.aaa1115910.bv.*` | `dev.frost819.newbv.app.*` |
| `@KoinViewModel` | `@HiltViewModel` + `@Inject` |
| Activity 生命周期管理播放器 | Compose `DisposableEffect` / `LifecycleEventObserver` |

### 6.2 执行逻辑（在 VideoPlayerController 中）

```kotlin
// Toggle 记忆：同一个 keyCode 按两次恢复之前的值
class PlayerCustomShortcutToggleMemory {
    private val memories = mutableMapOf<Int, Any>()

    fun <T> selectTarget(keyCode: Int, current: T, target: T): T {
        if (current == target) {
            // 当前值已是目标值，恢复之前的记忆
            @Suppress("UNCHECKED_CAST")
            return memories[keyCode] as? T ?: current
        } else {
            // 保存当前值，切换到目标值
            memories[keyCode] = current
            return target
        }
    }
}
```

### 7.3 Seek 加速逻辑

```kotlin
// 快速连按 left/right 时，每次 seek 距离递增
// 基础 10s，每 5 次连按增加 5s
private fun calCoefficient(): Long {
    val now = System.currentTimeMillis()
    if (now - lastSeekChangeTime < 200) {
        seekChangeCount++
    } else {
        seekChangeCount = 0
    }
    lastSeekChangeTime = now
    return 10_000L + (seekChangeCount / 5) * 5_000L
}
```

## 8. 屏幕生命周期管理

原版用 Activity 生命周期（onCreate/onResume/onPause/onDestroy），newBV 用 Compose 生命周期：

```kotlin
@Composable
fun VideoPlayerScreen(
    navController: NavController,
    playerViewModel: PlayerViewModel = hiltViewModel(),
    danmakuViewModel: DanmakuViewModel = hiltViewModel(),
    // ... 其他 VM
) {
    val context = LocalContext.current

    // 初始化播放器
    DisposableEffect(Unit) {
        playerViewModel.initVideoPlayer(context)
        onDispose {
            playerViewModel.detachPlayer()
        }
    }

    // 窗口全屏 + 隐藏系统栏
    DisposableEffect(Unit) {
        val window = (context as? Activity)?.window
        window?.let {
            WindowCompat.setDecorFitsSystemWindows(it, false)
            WindowInsetsControllerCompat(it, it.decorView).apply {
                hide(WindowInsetsCompat.typeSystemBars())
                systemBarsBehavior = WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE
            }
        }
        onDispose {
            window?.let {
                WindowCompat.setDecorFitsSystemWindows(it, true)
                WindowInsetsControllerCompat(it, it.decorView).apply {
                    show(WindowInsetsCompat.typeSystemBars())
                }
            }
        }
    }

    // 播放/暂停跟随生命周期
    LifecycleResumeEffect(Unit) {
        // onResume: 恢复播放
        onPauseOrDispose {
            // onPause: 暂停播放
            playerViewModel.togglePlayPause()  // 仅在 playing 时暂停
        }
    }
}
```

```kotlin
object PlayerConstants {

        ApiType.Web -> WEB_USER_AGENT
        ApiType.App -> APP_USER_AGENT
    }
```
